# V0.6.0 Grok Imagine 实施计划

## 目标

在 V0.5.0 的统一图片工具入口中加入 `grok-imagine-image`。工具只负责模型参数转换、请求、结果保存和摘要；Skill 把用户明确要求转换为底层参数，并逐张显示成功结果。

## 实施内容

- [x] 通过 `/v1/models` 确认模型 ID 为 `grok-imagine-image`。
- [x] 真实验证最小请求、一次三张、低中高质量、1K/2K、七种常用比例。
- [x] 真实验证 `/v1/images/edits` 参考图和修图请求。
- [x] 为 Grok 增加独立的 `resolution`、`aspect_ratio`、`response_format` 请求转换。
- [x] 按图片签名保存 JPEG 或 PNG，保持扁平输出和不覆盖旧图。
- [x] 更新 Skill、安装规则、README、版本规划和父项目生图分组方法页。
- [x] 完成 Go、Python、Skill、发布契约测试和两平台本地构建。
- [x] 只在本地提交子项目和父项目改动，不迁移公网资产、不推送。

## 验收

- Grok 文生图和修图都通过统一原生工具执行。
- `--resolution 1k|2k` 与七种 `--aspect-ratio` 值进入正确请求字段。
- `--n 3` 一次请求保存三个平铺图片，并在 stdout 返回三个 `output_files`。
- JPEG 和 PNG 都使用真实扩展名，输出目录没有请求记录或额外子目录。
- 安装器可以从 V0.5.0 升级到 V0.6.0，并保留现有专门画图分组 Key。
