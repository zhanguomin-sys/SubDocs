# V0.4.1 参考图、修图和多图实施计划

## 目标

在 `gpt-image-2` 现有文生图能力上完成参考图、图片修改和同一提示词多图结果。工具负责准确发送参数、保存最终图片；Skill 负责把每张结果显示在当前对话。

## 已完成

- [x] 增加固定 `/v1/images/edits` 接口和重复 `--image` 输入。
- [x] 输入图片只在内存和系统临时 multipart 文件中处理，不写入用户输出目录。
- [x] 增加 `--n 1..10`，单图返回 `output_file`，多图返回 `output_files`。
- [x] 中转站忽略 `n` 时，由同一次工具命令补齐剩余图片。
- [x] 所有最终图片直接保存到一个 `images` 目录，不创建图片专属子目录。
- [x] Skill 要求按 `output_files` 顺序逐张调用 `view_image`，全部显示后才能报告成功。
- [x] 增加 JSON、multipart、多图补齐、输入校验、扁平输出和 Skill 契约测试。
- [x] 使用真实接口验证参考图、图片修改和三张多图结果；测试后未保留 Key 副本。

## 不包含

- 蒙版、透明背景、JPEG/WebP、压缩率和其它低频参数。
- 其它图片模型和视频模型。
- 自动后台更新或计划任务。
