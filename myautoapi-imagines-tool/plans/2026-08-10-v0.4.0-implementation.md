# V0.4.0 文生图实施计划

## 目标

完成 `gpt-image-2` 文生图能力。Codex 只把用户要求转换成准确的底层参数，工具只调用固定接口并把最终 PNG 保存到容易找到的位置。

## 已确认边界

- 固定模型 `gpt-image-2`、固定接口、固定每次一张图。
- Skill 不增加用户没有要求的风格、内容、构图或画面元素。
- 常用尺寸和质量来自 2026-08-10 真实接口验证，并作为建议值写入 Skill。
- 项目存在时输出到项目 `images`；没有项目时输出到桌面 `images`。
- `images` 只保留最终图片，不创建图片专属子目录，不保存请求、响应头、原始响应或摘要文件。
- 成功只返回 `output_file`；失败只返回脱敏错误。
- 当前稳定输出固定为 PNG。

## 不包含
