# V0.7.3 Intel Mac 发布计划

## 目标

- 新增 `darwin/amd64` 原生构建。
- Mac 客户继续使用同一个 `install.sh`，自动选择 Apple Silicon 或 Intel 程序。
- Apple Silicon 在 Rosetta 下运行安装命令时仍选择 arm64 程序。
- 下载前后核对 SHA-256 和 Mach-O 架构，避免同版本错误架构被复用。
- 保留 V0.7.2 的 macOS Code Mode 结果转发和受限恢复行为。

## 发布资产

- `myautoapi-imagines-tool-v0.7.3-windows-amd64.exe`
- `myautoapi-imagines-tool-v0.7.3-darwin-arm64`
- `myautoapi-imagines-tool-v0.7.3-darwin-amd64`
- `SHA256SUMS`
- `install.ps1`
- `install.sh`

## 验证

- Go 单元测试、竞态测试和 `go vet`。
- Python 安装器、Skill、macOS Code Mode 和发布契约测试。
- 三个产物 SHA-256 与安装脚本内置哈希一致。
- `file` 确认两个 Mac 产物分别为 arm64 与 x86_64 Mach-O 可执行文件。
- 模拟 `Darwin/arm64`、`Darwin/x86_64` 和 Rosetta 分流。
- 父仓库发布资产测试和 VitePress 构建。
- 公网下载、哈希和隔离 `CODEX_HOME` 安装验证。

## 实机边界

本地交叉编译、Mach-O 检查和安装脚本模拟不能替代真实 Mac 运行。没有 Apple Silicon 或 Intel Mac 实机证据时，发布记录必须分别写明未实机验证。
