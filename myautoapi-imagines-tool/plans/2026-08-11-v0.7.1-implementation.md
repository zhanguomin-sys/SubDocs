# V0.7.1 多模型并发与展示实施计划

## 目标

修正多模型任务被旧 Skill 规则强制顺序执行的问题。不同模型分别保留一个独立原生工具调用，但由 Codex 在同一批中并发启动；结果按准确模型 ID 绑定并逐张显示。

## 已完成

- [x] Skill 将多模型比较从逐个调用改为宿主并发工具调用。
- [x] 禁止用 shell 后台符号、`Start-Job`、脱离会话任务和进程轮询模拟并发。
- [x] 保留单模型一次调用和同模型 `--n N` 一次调用的原有边界。
- [x] 为模型、工具调用和 stdout 结果建立明确对应关系。
- [x] 每个成功文件调用 `view_image` 前写出准确模型 ID，同一模型多张图时同时写出当前张数。
- [x] 一个模型失败时继续展示其它成功结果，并单独报告失败模型。
- [x] 同步安装到用户 `AGENTS.md` 的全局规则和无密钥契约测试。
- [x] 允许 V0.7.0 原生安装直接升级并保留已有专门 Key。

## 发布边界

- 本版本不新增模型，不改变 API 请求、参数、图片解析和保存逻辑，不需要重新消耗真实生图额度。
- 只构建 Windows x64 和 Apple Silicon Mac 两个平台程序。
- 父仓库迁移、公网站点发布和真实 Codex 多模型并发验证另行执行。
