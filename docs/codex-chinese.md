# 将 Codex 界面切换为简体中文

在 Codex 或新版 ChatGPT 桌面端打开 **Settings（设置）→ General（常规）→ Language（语言）**，选择 **简体中文（中国）**，然后完全退出并重新打开应用。

Windows 用户也可以用 [MyAutoAPI 接入助手](/quick-connect)：点击「设为简体中文」会保存 Codex 的语言偏好。已有配置会先备份。macOS 用户可直接使用应用内的语言选项。

如果仍显示英文，请先更新官方桌面应用，在可以连接 OpenAI 的网络中重新打开，并检查设置里是否保留了所选语言。有些版本在离线启动时会回退为英文，或只翻译部分界面。这取决于官方应用的版本和语言支持情况，见 [Codex 的语言设置问题](https://github.com/openai/codex/issues/19239)。
