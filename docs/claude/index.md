# Claude

MyAutoAPI 的 Claude 模型可以接到 Claude Code（终端里的编程助手）和 Claude Desktop（桌面应用）。两者配置入口不同，按你用的工具进入：

| 你用的工具 | 进入 |
| --- | --- |
| Claude Code（终端） | [Claude Code 接入](/claude/claude-code) |
| Claude Desktop（桌面应用） | [Claude Desktop 接入](/claude/desktop) |

在 Cherry Studio、Trae 等其它客户端里用 Claude 模型，Key 选 **CC MAX 外接分组**，按 [其他工具](/clients/#模型怎么填) 填写。

Claude 模型名和价格看 [模型价格](/models)。
