# MyAutoAPI.com 中转站教程

MyAutoAPI 中转站让 Codex 使用 AI 模型，并支持在对话中生成、修改图片。首次接入先看“快速开始”，用接入助手一键导入；助手和命令都不行时选“CC Switch 接入”，接入后再安装生图工具、导入国产模型。

<div class="home-entry-grid">
  <a class="home-entry home-entry--main" href="/quick-start">
    <span>1. 新手入口</span>
    <strong>快速开始</strong>
    <p>下载接入助手，粘贴密钥后连接 Codex。</p>
  </a>
  <a class="home-entry home-entry--switch" href="/codex-cc-switch">
    <span>2. 图形化接入</span>
    <strong>CC Switch 接入</strong>
    <p>不想运行脚本时，用图形工具导入 Codex 配置。</p>
  </a>
  <a class="home-entry home-entry--image" href="/image-video-group-image">
    <span>3. 在 Codex 中生图</span>
    <strong>安装生图工具</strong>
    <p>让 Codex 直接生成、修改图片，并在对话中展示成品。</p>
  </a>
  <a class="home-entry home-entry--models" href="/codex-models">
    <span>4. 扩展模型选择</span>
    <strong>导入国产模型</strong>
    <p>一键把国产模型加入 Codex 模型列表，保留原有 GPT 配置。</p>
  </a>
</div>
