## Windows 导入精简重构（2026-10-16）

原 Windows 导入用自制偏移排序改配置，又叠加事务、快照核对、回滚与读回比对，用户在 Windows PowerShell 5.1 上持续得到“TOML 配置行无效”，而 PowerShell 7 的 3.4 万个随机配置（含 CRLF、注释、多行值、已有目录与桌面段）都无法复现。最可能的嫌疑是 5.1 的 `Sort-Object` 对哈希表键排序行为不同导致修改点错位，这一点没有在 5.1 上证实。本轮不再依赖该排序：改为按语句序号替换/插入，不移动偏移；删除事务、回滚、读回比对；写入前只核对新配置能解析且两项取值正确。

同时修正：官方模型不再只保留 `gpt-` 开头，隐藏的 `codex-auto-review` 补回快照并随缓存保留；缓存版本不低于快照才覆盖；重复导入以缓存刷新官方条目，用户自定义条目保留；`key =` 无值时给出明确错误，不再抛出 Substring 异常；卸载不再读写 `config.toml`。

用 PowerShell 7.6.7 完成：随机配置 21647 与 12705 个有效样本修改后全部可解析且取值正确（旧代码有 131 个因空值崩溃）；用本机真实 `models_cache.json` 生成目录，真实 Codex 0.162.1 `debug models` 成功加载 23 个模型（含隐藏条目与 10 个国产模型）；完整回归 49/49，上层发布检查 11/11。Windows PowerShell 5.1 仍未实机验证，由用户测试。
